# 🎙️ Speakify v1  
## AI-Powered Voice Assistant

Speakify v1 is a Streamlit-based AI voice assistant that converts user voice input into text, generates intelligent contextual responses, and replies back using natural AI-generated speech.

This is **Version 1**, focused on building a stable voice-to-voice AI pipeline with a modern, colorful SaaS-style interface.

---

# 🚀 Features

- 🎧 Upload recorded audio (mp3, wav, m4a)
- 🧠 Context-aware AI conversation memory
- 🔊 Text-to-Speech AI replies
- 🎛 Voice selection option
- 💬 Modern chat-style UI
- ⬇ Download AI-generated voice response
- 🗑 Clear conversation functionality
- 🎨 Responsive and colorful industry-style interface
- ⚡ Real-time processing pipeline

---

# 🛠 Tech Stack

## Language
- Python  

## Framework
- Streamlit  

## AI Models Used
- `gpt-4o-transcribe` – Speech-to-Text  
- `gpt-4o-mini` – AI response generation  
- `gpt-4o-mini-tts` – Text-to-Speech  

## Environment Management
- python-dotenv  

## State Management
- Streamlit Session State

# 🧪 Example Workflow

1. Upload a recorded voice file  
2. Speakify transcribes the audio into text  
3. AI generates an intelligent response  
4. The response is converted into speech  
5. The AI voice and need to press play button 
6. User can download the generated audio
